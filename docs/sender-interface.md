# 发送界面、等待虚框与速率统计

发送页按文件、传输设置、准备与播放分组。宽窗口使用双栏，右侧保留限制说明和日志；窄窗口使用单栏。序列化操作栏固定在底部。

点击序列化后，在上传和编码等待期间显示播放区域的虚线框。预生成开关开启或关闭时均会显示。等待框和正式播放使用同一个网格容器；准备完成时切换内容，不移动播放区域。等待期间可以返回设置或取消任务，失败时返回设置并显示日志入口。虚框表示播放区域，不表示实际编码完成百分比。

播放工具栏提供三个读数：

- 发送速率：最近两秒实际呈现的编码负载字节数除以时间，预热期使用实际经过时间；每 250 毫秒刷新一次。
- 显示帧率：最近两秒实际呈现帧数除以时间及码数，表示单码的平均 FPS。累计帧数包含网格内各码的呈现。
- 累计发送：本次播放已呈现的编码负载字节数。暂停后继续保留累计值，新序列化任务重新计数。

服务端从实际协议帧提取负载长度，通过本机 HTTP 响应头 `X-QRT-Payload-Bytes` 告知网页。普通 QR / Color 不计 QRT2 头和文件名帧；Decimen 不计帧头。网页仅在 PNG 解码完成并替换到播放网格时累计，预取、失败请求、未显示的图片及 PNG 压缩体积不计入。缺失或无效的计数头显示「—」，不按分片大小猜测。

该指标包含编码填充、喷泉冗余及轮播重发，不代表接收端成功恢复的原始文件速度。Decimen 的负载也包含其容器数据。无反馈光学信道无法由发送端确认接收成功量；Horizon 还可能丢弃网页之后的画面更新，文件恢复的 Goodput 应以接收端确认的原始文件字节数和完成耗时计算。

暂停时速率归零；暂停前的速率窗口不会带入恢复后的窗口。播放卡顿时即使没有新帧，工具栏仍会刷新，旧样本在两秒后退出窗口。统计不触发额外 HTTP 请求，不改变光学协议及编码参数。
