# QRT Pro v2.0.0

## 升级说明

经典 QR / Color 模式改用 QRT2：新增随机会话身份、全帧 CRC 和原始文件 SHA-256 校验。**发送端与 Windows/Android 接收端必须同时更新**，旧经典帧不兼容。decimen 的 D1 0D + DCF2 线格式保持不变。

## 主要修复

- 修复跨会话混流、静默损坏、Online 整数溢出、RaptorQ 欠秩误完成及单块文件边界问题。
- 增加输入、解码与缓存预算；编码/PNG 生成运行于可终止、受限的本地 worker，无新增网络通信。
- Android 解码、解压与校验移至后台有界队列，重扫隔离旧任务；修复保存失败误报、权限和文件发布流程。
- 浏览器预取下一帧并在解码完成后呈现；修复重复调度、固定 QR 几何、交错公平性及资源清理。
- 修复 GDI bitmap 生命周期、过长扩展名、decimen 校验失败重试和会话过期问题。
- Kotlin 矩阵使用基础数组降低分配，保留原有算法和随机索引规则。

Android：versionCode 11 / versionName 2.0.0。

## 验证与边界

本地 Go 五包 race、Kotlin 37 项测试及真实 Chrome 回归通过。远程发布流程进一步执行 Android release 单元测试并生成 APK。Windows GDI/Job Object 和 Android 相机/存储的真机验收仍需进行；没有将局部分配收益宣称为端到端光学提速。

新增资源预算可能拒绝协议参数合法但计算/内存开销过高的传输。详见仓库中的协议说明和修复记录。
