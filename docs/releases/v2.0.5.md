# QRT Pro v2.0.5

- 优化发送网页：宽窗口双栏卡片布局、窄窗口单栏，固定底部操作栏，设置、限制和日志分区展示。
- 点击序列化后显示播放区域虚框；预生成开启或关闭时均展示，准备完成后在同一区域播放二维码。
- 等待期间可返回设置或取消，失败时返回设置并显示日志入口。
- 播放工具栏新增发送速率、显示 FPS 和累计发送量。速率按最近两秒实际呈现的编码负载统计，不计预取、协议头、文件名帧或 PNG 体积；暂停归零，卡顿时旧样本退出窗口。
- 补充真实 Chrome 的布局、等待虚框、位置保持、取消/失败返回和键盘操作回归，以及跨模式负载计数、暂停/卡顿、缺失统计头和 30/60 FPS 调度验证。

发送速率包含喷泉冗余、填充和轮播重发，不代表接收端成功恢复原始文件的速度。Horizon 也可能丢弃网页之后的画面更新。详见 [统计口径及界面说明](https://github.com/Brucegot9stars/txqr-pro/blob/v2.0.5/docs/sender-interface.md)。

传输算法、光学协议及容量限制保持兼容，接收端可继续使用 v2.0.0+。更新发送程序后刷新网页，确认显示 v2.0.5。Android：versionCode 16 / versionName 2.0.5。

下载：

- `qrt-pro-windows-amd64-v2.0.5.exe`：Windows 统一收发客户端。
- `qrt-pro-sender-windows-amd64-v2.0.5.exe`：Windows 独立网页发送服务。
- `qrt-pro-reader-v2.0.5.apk`：Android 接收端。
