# QRT Pro v2.0.4

- 发送页使用「预生成全部二维码」开关选择准备方式，替代下拉列表。
- 开启：先生成整轮二维码再播放，准备等待较长、播放期间生成开销较低。
- 关闭（默认）：先准备首批，后续边生成边播放，缩短开始等待。
- 开关选择在下次序列化生效；界面显示两种方式的区别和缓存约束。
- 覆盖开关两种状态的请求参数与真实 Chrome 交互回归。

传输协议、算法及容量限制与 v2.0.3 相同，接收端可继续使用 v2.0.0+。更新发送程序后刷新网页，在顶部确认 v2.0.4。Android：versionCode 15 / versionName 2.0.4。

下载：

- `qrt-pro-windows-amd64-v2.0.4.exe`：Windows 统一收发客户端。
- `qrt-pro-sender-windows-amd64-v2.0.4.exe`：Windows 独立网页发送服务。
- `qrt-pro-reader-v2.0.4.apk`：Android 接收端。
