# QRT Pro v2.0.6

- 修复普通 QR / Color 偶发保存为 `received.bin`：文件名由每轮单独发送一次改为分散发送 3 次，数据帧和编码算法保持兼容。
- Go / Kotlin 核心解码器允许内容恢复后补收同一会话的有效文件名，拒绝损坏帧和其他会话，后续冲突名称不会覆盖第一个名称。
- Windows / Android 在内容已校验但文件名缺失时继续补收约 3 秒；收到名称立即完成，超时使用默认名称并提示。正常收到文件名的传输不增加等待。
- 超时由接收生命周期独立检查，即使没有后续画面也会结束；取消、重启和旧代任务不会重复保存或覆盖新任务。
- 补收不重复解码、不增加编码字节统计，内容恢复耗时保持冻结。Decimen 文件名仍由受保护的 DCF2 容器恢复，流程不变。
- 增加五种经典算法/小文件、前两次名称丢失、迟到/损坏/其他会话元数据、无新画面超时、单次发布及 Go→Kotlin 共享向量回归。

建议发送端和接收端都升级，以同时获得三次发送和完成后补收。与 v2.0.0+ 的 QRT2 / Decimen 继续互通；仅升级发送端也能提高名称帧覆盖率，旧接收端仍会在内容完成后停止。3 次重复不能保证连续丢帧时必定收到名称，界面会明确显示兜底情况。

更新发送程序后刷新网页，确认 v2.0.6。Android：versionCode 17 / versionName 2.0.6。
